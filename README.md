# SafeRoute AI – Safety-Focused Navigation App

## Project Overview

SafeRoute AI is a UI/UX design concept focused on making everyday navigation more safety-conscious and user-friendly. The project explores how users can consider personal safety alongside travel time and convenience when choosing a route.

The goal is to design a simple and intuitive mobile experience that helps users make informed travel decisions and access emergency assistance options easily.

## Problem Statement

Most navigation experiences focus primarily on finding the fastest or shortest route. However, users may also have safety concerns when travelling alone or navigating unfamiliar locations.

SafeRoute AI explores how a user-centered interface can address these concerns through clear route comparisons, accessible emergency assistance, and location-sharing features.

## Project Objectives

- Design a simple and intuitive mobile navigation experience.
- Explore ways to present safety-related information during route selection.
- Make emergency assistance options easy to identify and access.
- Improve usability through clear navigation and consistent interface design.
- Create an experience that addresses real-world user needs.

## Key Features

**Destination Search:** A straightforward interface for entering and finding destinations.

**Safety-Focused Route Comparison:** A proposed experience for comparing available routes using safety-related information alongside convenience.

**Navigation Interface:** A clear layout that helps users understand their selected route.

**SOS Emergency Assistance:** An interface concept that provides quick access to emergency assistance options.

**Location Sharing:** A proposed feature that allows users to share their location with trusted contacts.

## Design Process

### 1. Problem Identification
Explored the challenges users may face when choosing routes based on personal safety and convenience.

### 2. User Persona
Developed a user persona to understand the target user's goals, travel habits, and safety concerns.

### 3. User Journey Mapping
Mapped the user's journey from searching for a destination to selecting a route and reaching the destination.

### 4. User Flow
Structured the main navigation flow, including destination search, route comparison, route selection, navigation, and access to emergency assistance.

### 5. UI Design
Designed mobile interfaces with a focus on visual hierarchy, consistent styling, readability, and ease of use.

### 6. Prototyping
Used Figma to create the interface designs and connect screens into a prototype, where applicable.
